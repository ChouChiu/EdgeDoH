# HANDOFF.md

This document records traps, pitfalls, edge cases, and lessons learned across development, deployment, and configuration tasks.

> **Rule for Agents:**  
> 1. Check this file **before starting any new task** to avoid repeating past mistakes.  
> 2. Append new findings and pitfalls encountered during tasks immediately.

## Pitfall Log & Lessons Learned

| Date | Category | Issue / Trap Encountered | Root Cause & Solution |
| :--- | :--- | :--- | :--- |
| *(Initial)* | Setup | Placeholder | Document issues here as they are resolved. |
| 2026-10-25 | Tooling | `wrangler types` and `tsconfig` layout | `wrangler types [path]` supports explicit output path (`src/worker/worker-configuration.d.ts`), which automatically shortens module imports to `./index`. Sub-tsconfigs placed in `tsconfig/` must resolve relative paths (`../src/*`) while keeping `@/*` alias in root `tsconfig.json` for shadcn CLI. |
| 2026-10-25 | Config | `wrangler.example.jsonc` placeholders | Wrangler rejects an empty string id (`"kv_namespaces[0]" bindings should have a string "id" field`), so the example config must use non-empty placeholders (`<kv-namespace-id>`). The local D1/KV state in `.wrangler/state` is keyed by that string, so tests and `bun run dev` work with placeholders unchanged. |
| 2026-10-25 | Deployment | Untracked `wrangler.jsonc` breaks the Deploy button | `wrangler.jsonc` holds account resource IDs and is now gitignored (template: `wrangler.example.jsonc`, created automatically by `bun run setup`). The Deploy to Cloudflare flow reads the wrangler config from the forked repository, so that path requires committing a copy of the example to your own fork and pointing the button's `url` at it. |
| 2026-10-29 | Web / animate-ui | Generated icons fail `tsc -b` | `shadcn add @animate-ui/icons-lucide-*` (registry in `components.json`) writes files with an unused `import * as React from 'react'`, which `noUnusedLocals` rejects. Delete that line after adding a new icon. Icons default to `size={28}` attributes; containers that size `svg` by CSS (Button, sidebar, menu items) override it, anywhere else pass a `size-*` class. |
| 2026-10-29 | Web / animate-ui | Where icon hover animations come from | `Button` and `DropdownMenuItem` (shared/ui) wrap themselves in `<AnimateIcon asChild animateOnHover>`, so any animate-ui icon inside plays on hover with no extra code; other hosts (sidebar nav, theme switch, links, stat cards) wrap explicitly. Spinners use `<LoaderCircle animate />` instead of `animate-spin`. Lucide icons with no animate-ui counterpart (ban, database, flask-conical, languages, list-checks, monitor, network, package-plus, power-off, scroll-text, shield-ban) are hand-written in `animate-ui/icons/` in the registry format, with the original lucide paths; they are not in the registry, so `shadcn add` cannot refresh them. Keep the original glyph rather than substituting a different animate-ui icon. |
| 2026-10-29 | Web / transitions | Page transition is React `<ViewTransition>`, not NavLink `viewTransition` | `PageTransition` (animate-ui, via `motion/react-animate-view`) animates on React transitions, which the data router already uses for every navigation. Do not also pass `viewTransition` to links: that starts a second document transition. `::view-transition-old(.page-transition)` stays hidden in `index.css` to avoid Chrome's GPU white-block snapshot bug in dark mode. Phones render the Outlet without it. `motion` adds ~54 kB gzip to the main client chunk (81.7 → 135.7 kB). |
| 2026-10-29 | Web / animate-ui | Tabs slide via the packaged primitive, not a vendored copy | `shared/ui/tabs.tsx` imports `@animate-ui/react/primitives/radix-ui/tabs` (same Root/List/Trigger/Content API as Radix). Its List copies the active trigger's computed surface into a sliding `[data-slot=tabs-indicator]` and makes the real trigger transparent, so the shadcn classes keep working unchanged. A query-string change (e.g. `?range=`) keeps the pathname, but the router still runs it as a React transition, so the page body gets a ViewTransition *update*: its default cross-fade with the old snapshot hidden blinks the page. PageTransition passes a zero-duration `update` to swap instantly; animate within the page instead. In tests, Radix selects tabs on `mousedown`: a synthetic `click()` does nothing. |
| 2026-10-29 | Web / animate-ui | Shared overlays and controls are animate-ui's Radix primitives | `dialog`, `alert-dialog`, `dropdown-menu`, `popover`, `select`, `tooltip`, `switch`, `checkbox` in `shared/ui` import `@animate-ui/react/primitives/radix-ui/<name>` as the primitive namespace (same parts as `radix-ui`). They animate open/close with motion, so the shadcn `animate-in/out`, `fade-*`, `zoom-*`, `slide-*` and `duration-100` classes were removed: re-adding them doubles the animation. The switch thumb is moved by measuring its CSS rest position, so it must not get a `transition-transform` back. `sheet` still uses plain Radix plus CSS slides. |
| 2026-10-29 | Tooling | Browser checks of animations | After `shadcn add` or new deep imports, Vite re-optimises deps mid-session (`504 Outdated Optimize Dep`) and the open page keeps stale modules: reload before judging a broken animation. When the Browser pane is hidden its animation frames are throttled, so frame-sampled opacity can read 0 mid-animation; read the final state after a pause instead. |
| 2026-10-29 | Web / animate-ui | `shadcn add @animate-ui/icons-*` writes to `src/components` | The CLI resolves the registry's own paths, so new icons land in `src/components/animate-ui/icons/` with an extra `icon.tsx`, `slot.tsx` and `src/hooks/use-is-in-view.tsx`. Copy only the icon file into `src/web/shared/components/animate-ui/icons/`, change its import to `'@animate-ui/react/icons'`, drop the `React` import, then delete `src/components` and `src/hooks`. |
| 2026-10-29 | Filter / snapshot | Snapshot lists now have kinds | `ListInfo.kind` is `filter` (absent in old snapshots), `service` (`service:<id>`, one per AdGuard blocked service, always compiled but applied only through a profile's `active` mask) or `route` (split-DNS domains, never applied as filters; exact names are widened to suffixes). `inspect()` returns the verdict plus the service and route the name belongs to in one pass. The CLI `compile`/`upload` commands still only compile filter lists: uploading from the CLI drops services and route lists until the dashboard recompiles. |
| 2026-10-29 | Worker / runtime config | KV runtime config moved to `config:v2` | Devices became objects (`{ name, profile?, pausedUntil? }`) and profiles, route upstreams and local records were added, so the key was versioned; the first DoH request after deploying seeds it from D1. Profile, pause, route and record changes reach other isolates within about a minute (30 s KV `cacheTtl` + 30 s isolate check), same as settings. The DoH path now loads the snapshot even when filtering is off for a query, because service attribution and split-DNS routing come from the same lookup. |
| 2026-10-29 | Worker / DoH | ECS and HTTPS injection caveats | Cloudflare's resolvers ignore EDNS Client Subnet; it only helps with upstreams that honour it: AliDNS and DNSPod changed their answers by subnet in a 2026-10-29 test, Google did not. With ECS on, cache keys include the subnet, so the hit rate drops; a client-sent ECS with source prefix 0 (opt-out) is honoured. Cache keys also include the upstream set, because profiles and split-DNS routes send one name to different resolvers. ECH/H3 injection edits HTTPS records only when every hint or A address is in Cloudflare's published ranges (hard-coded in `https-inject.ts`, update if https://www.cloudflare.com/ips/ changes), skips DO-bit queries since edited records would not validate, and takes the ECH config from `cloudflare-ech.com`'s HTTPS record, cached in memory for at most 5 minutes. |
| 2026-10-29 | Worker / DoH | One verdict pipeline for DoH and the rule tester | `doh/decide.ts` owns the order (local records, disabled-IPv6 shortcut, profile lists and services, safe search); `/api/rules/test` is served by `doh/api.ts` (mounted before `/rules`) and calls the same function, so the tester cannot drift from real answers again. Local records win over the disabled-IPv6 shortcut. |
| 2026-10-29 | Services | Domestic services come from community rule sets | AdGuard's catalog has few mainland-China apps, so `/api/services` also downloads per-app Clash lists from blackmatrix7/ios_rule_script (GPL-2.0, fetched at runtime, never bundled; mapping in `services/api.ts`). Only `DOMAIN` / `DOMAIN-SUFFIX` lines convert; keyword, IP and process rules are dropped. There is no Taobao-only set (its `Alibaba` set also covers Alibaba Cloud and AliDNS), so it is left out. AdGuard's `tiktok` service already includes Douyin domains. A source that fails is omitted; the endpoint errors only when every source fails. Registry icons draw with `currentColor`, so `ServiceIcon` uses them as a CSS mask (an `<img>` would render them black in dark mode); community services show their first character. |
| 2026-10-29 | DoH / ECH | Checking ECH from a browser behind a proxy always shows `sni=plaintext` | With an HTTP/SOCKS proxy (Clash and the like, or its fake-ip DNS) the browser hands the hostname to the proxy and never looks up the HTTPS record, so injected ECH is never used. Verify with the proxy off: `dig @<domain> +https=/dns-query/<device> www.cloudflare.com HTTPS` should show `ech=`, then `https://www.cloudflare.com/cdn-cgi/trace` should show `sni=encrypted`. Queries with the DO bit are deliberately left uninjected. |
| 2026-10-29 | Architecture | Where shared values and cross-feature calls go | Limits and enums both the Worker and the dashboard check (upstream count, name lengths, blocking/upstream modes, record types, stats ranges/actions/sources, reserved list IDs) live in `src/lib/contract` (`#contract`); feature modules re-export them so existing imports keep working. Worker-only validators (`isOneOf`, `UPSTREAMS_ERROR`) are in `src/worker/shared/validate.ts`. A web feature may import another feature only through its `api.ts` (types, query keys, query/mutation hooks such as `useListAction` and `useRebuild`); components stay inside their feature, cross-feature UI goes to `shared/`. Destructive confirmations use `shared/components/confirm-dialog.tsx`. Knip flags `src/worker/test/env.d.ts` as unused, but it is a global type augmentation picked up by `tsconfig/worker.json`; keep it. |
| 2026-10-29 | Web / tests | Component tests run in happy-dom with animations off | `.test.tsx` files under `src/web` start with `// @vitest-environment happy-dom` and run in the `node` Vitest project (which also maps `@/`). happy-dom cancels motion's Web Animations mid-flight and the AbortError surfaces as unhandled rejections that fail the run, so `src/web/test/setup.ts` sets `MotionGlobalConfig.skipAnimations`. Wrap components in `I18nProvider` (set `localStorage.locale` first for stable text) and, for anything calling `useRebuild`, `RebuildContext.Provider` from `@/features/snapshot/api`. |
| 2026-10-29 | Web / bundle | Pages stay in the main bundle | `routes.tsx` deliberately avoids lazy routes so navigation never flashes a fallback and the page cross-fade captures the new page. The >500 kB warning was fixed by giving `motion` and `@animate-ui` their own vendor chunk in `vite.config.ts` instead (main chunk 606 → 352 kB); all chunks still load up front. |
| 2026-10-29 | Worker / DoH | ECH for censored networks: forced names, CNAMEs, stored config | Injection judges the owner at the end of the CNAME chain (zones on CNAME setup point at `*.cdn.cloudflare.net`) and re-emits the CNAMEs with explicit owner names. The global `echForcedDomains` setting (profiles with ECH or H3 on) skips the Cloudflare-range check and the extra A lookup for listed names and their subdomains; A/AAAA answers are never rewritten (a preferred-IP rewrite was built and then dropped at the user's request). Research (FOCI 2025) says China blocks ECH indirectly by blocking encrypted DNS, so the DoH endpoint's own reachability matters most. The ECH config is served stale while refreshed in the background and its last good value is kept in RULES KV under `ech:config` (written only when it changes, after a read), so a cold isolate whose upstream cannot resolve `cloudflare-ech.com` still injects. `resetEchMemo()` is a test hook: Vitest shares the Worker's module instance, so tests can clear the memo. |
| 2026-10-29 | Web / motion | Reduced motion and motion speeds | `main.tsx` wraps the app in animate-ui's `ReducedMotionConfig` (a `MotionConfig` with `reducedMotion="user"`), so every motion-driven primitive, `SlidingNumber` and icon follows the OS setting; the `@media (prefers-reduced-motion: reduce)` block at the end of `index.css` covers CSS transitions, keyframes and view transitions. Under reduced motion `<LoaderCircle animate />` stops spinning, so loading states must keep their text. Speeds are documented on the `@theme` block in `index.css` (150 ms feedback, 200 ms in-place movement with `ease-standard`, 450 ms only for whole-screen changes). Recharts areas default to a 1.5 s draw; the overview passes 400 ms ease-out and turns it off under reduced motion via `useShouldReduceMotion`. |
| 2026-10-29 | Web / layout | Overview structure, sidebar groups, page headers | The overview's four headline numbers and the trend chart share one `Card`: the numbers sit in a `gap-px bg-border` grid (cells paint `bg-card`; an empty slot shows as a grey block, so keep the cell count a multiple of the columns, 2 on phones and 4 on `lg`). Domains, blocked and devices rankings stay visible; the other six are tabs in one card (`MoreRankings`), and Radix unmounts inactive panels, so only the active ranking is queried (4 top requests per view instead of 9). Switching to the phone viewport remounts the page (App drops PageTransition on phones), which resets that tab. The sidebar renders `NAV_GROUPS` (spacing only, no labels) plus `SETTINGS_NAV` in the footer, which stays visible when collapsed. The header page title is phone-only. `PageHeader.description` is a live status line (Filters shows the snapshot summary there, with Rebuild as the action) or nothing: static descriptions that restated the nav label were removed with their strings; logs, rules and install keep theirs because they state limits or a safety warning. The device setup guide is a native `<details>` whose `open` is only an initial value. Settings has a sticky section index on `lg` (`SECTIONS` in `settings-page.tsx`, `Section id`); it uses buttons with `scrollIntoView`, not `#hash` links, which would go through the router. |
| 2026-10-29 | Web / typography | Type roles and the Noto Serif fonts | Text roles are `@utility type-*` in `index.css` (display, figure, title, subtitle, heading, meta; body is Tailwind's default); use them instead of ad-hoc `text-*`/`font-*` pairs. Serif = Noto Serif, never paragraphs or controls. Inside `@utility` read theme values with `--theme(--font-serif)`, not `var()`: with `@theme inline` the variable is not guaranteed to exist at runtime. Importing `@fontsource-variable/noto-serif-sc`/`-tc` from `index.css` put 200+ `@font-face` blocks into the render-blocking CSS (17 to 100 kB gzip), so `shared/lib/fonts.ts` imports the active locale's sheet on demand from `I18nProvider` (SC ~37 kB, TC ~44 kB gzip; English loads neither). The woff2 slices add ~13 MB and ~210 files to `dist/client/assets`, but a page only downloads the slices for glyphs it shows. `:root:lang(zh-Hant)` puts TC before SC. |
| 2026-10-29 | Tooling | Browser pane screenshots crop the viewport | With a large emulated viewport the pane's screenshot showed only the top-left part of the page. Check layout numerically (`getComputedStyle(...).gridTemplateColumns`, `scrollWidth - clientWidth`) or use the `mobile` preset. Stats are unconfigured locally (503); to see the overview with data, replace `window.fetch` for `/api/stats/*` in the page and navigate with `history.pushState` + a `popstate` event so the mock survives. |
