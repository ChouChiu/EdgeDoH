| 2026-10-25 | Tooling | `wrangler types` and `tsconfig` layout | `wrangler types [path]` supports explicit output path (`src/worker/worker-configuration.d.ts`), which automatically shortens module imports to `./index`. | 2026-10-29 | Web / animate-ui | Where icon hover animations come from | `Button` and `DropdownMenuItem` (shared/ui) wrap themselves in `<AnimateIcon asChild animateOnHover>`, so any animate-ui icon inside plays on hover with no extra code; other hosts (sidebar nav, theme switch, links, stat cards) wrap explicitly. | 2026-10-29 | Worker / DoH | ECS and HTTPS injection caveats | Cloudflare's resolvers ignore EDNS Client Subnet; it only helps with upstreams that honour it: AliDNS and DNSPod changed their answers by subnet in a 2026-10-29 test, Google did not. With ECS on, cache keys include the subnet, so the hit rate drops; a client-sent ECS with source prefix 0 (opt-out) is honoured. Cache keys also include the upstream set, because profiles and split-DNS routes send one name to different resolvers. ECH/H3 injection edits HTTPS records only when every hint or A address is in Cloudflare's published ranges (hard-coded in `https-inject.ts`, update if https://www.cloudflare.com/ips/ changes), skips DO-bit queries since edited records would not validate, and takes the ECH config from `cloudflare-ech.com`'s HTTPS record, cached in memory for at most 5 minutes. |
| 2026-10-29 | Worker / DoH | One verdict pipeline for DoH and the rule tester | `doh/decide.ts` owns the order (local records, disabled-IPv6 shortcut, profile lists and services, safe search); `/api/rules/test` is served by `doh/api.ts` (mounted before `/rules`) and calls the same function, so the tester cannot drift from real answers again. Local records win over the disabled-IPv6 shortcut. |

They stay separate files because the licenses differ. Aggregate, ad and category sets (ChinaMax, Proxy, Advertising, Game, STUN…) are excluded in its `config/community.ts`; `OVERRIDES` there pins the IDs and Chinese names cf-dns shipped first (`douyin`, `jd`, `mango_tv`…), which profiles store. The Worker's `/api/services/:source` passes each file through unparsed (~1 MB together would eat the free plan's CPU budget); the dashboard's `mergeCatalogs` validates them and merges same-ID services (AdGuard's name and icon win, community rules are added). | 2026-10-29 | Filter / compile | Rules dedupe within a list, never across lists | `compile` used to drop a rule already seen in an earlier list. Profiles apply lists and services one by one through the `active` mask, so that lost the rule from the later list: a profile enabling only OISD Big missed 87k of its 235k rules (shared with AdGuard DNS filter and HaGeZi Pro), blocking only AppleMusic did not block `music.apple.com` when Apple came first, and a domain in any filter list lost its service name. | 2026-10-29 | DoH / ECH | Checking ECH from a browser behind a proxy always shows `sni=plaintext` | With an HTTP/SOCKS proxy (Clash and the like, or its fake-ip DNS) the browser hands the hostname to the proxy and never looks up the HTTPS record, so injected ECH is never used. Queries with the DO bit are deliberately left uninjected. |

| 2026-10-30 | Worker / DoH | Rebinding protection runs after the cache, and an upstream's 0.0.0.0 counts | The edge cache key has no profile, so `handler.ts` checks every pass answer from upstream or cache, not at write time.
